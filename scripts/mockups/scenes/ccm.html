Guide Bootstrapping

Install a preset in one command

Pick the preset closest to your work. The installer previews every change first, backs up ~/.claude, and merges settings instead of overwriting them.

~/claude-code-mastery — zsh
❯ ./install.sh --preset backend-python --dry-run
Preset  Backend — Python  FastAPI/Django services
Backup  ~/.claude → ~/.claude.backup-20261013-0941  (dry run, not written)

  + skill  engineering/api-design-reviewer
  + skill  engineering/pr-review-expert
  + skill  reference/fastapi-patterns
  + agent  backend-architect, debugger, code-reviewer-pro
  + hook   pre-tool-use/block-main-branch
  + hook   pre-tool-use/block-secret-reads
  ~ merge  settings.json  keeps your model, env, permissions.allow
  = skip   CLAUDE.md  edited by you since last install

❯ Looks right? Run without --dry-run. Undo any time with --uninstall.
Backs up first. Timestamped copy and a restore command.
Merges settings. Deny rules and hooks are unioned in.
Never clobbers edits. Changed files are reported and skipped.
Reversible. Uninstall removes exactly what it added.
